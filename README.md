# Projeto para Seletivo PETComp 2024
Este é o projeto que desenvolvi para ingressar no grupo PETComp, em outubro de 2024. A proposta consistia em uma atividade simples de desenvolvimento web, aplicando os conceitos básicos de HTML e CSS na criação de um evento fictício de escolha própria.

Essa foi minha primeira experiência com desenvolvimento web, aos poucos iniciando esse contato apenas no 6º período da universidade. Gostei muito da experiência na época e consegui aprender bem os fundamentos da área.

Uma curiosidade: meu conhecimento sobre desenvolvimento web era tão básico que utilizei o próprio Bloco de Notas como editor de código. Apesar da experiência praticamente nula e da simplicidade do projeto, consegui ser aprovado em 1º lugar no seletivo.

Atualmente, a etapa de desenvolvimento web se tornou oficial no processo seletivo do PETComp, mas passou a ser um pouco mais complexa, incluindo a exigência de um carrossel. Assim como a própria etapa do seletivo, também evoluí bastante na área de desenvolvimento web. Ao longo desse período, aprofundei meus conhecimentos em HTML e CSS e passei a utilizar PHP e JavaScript em projetos desenvolvidos em equipe.
